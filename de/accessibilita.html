    Barrierefreiheit

    Die Website ist so gestaltet, dass sie mit Tastatur, Screenreadern, Vergrößerung und Mobilgeräten nutzbar ist. Ziel: WCAG 2.2, Stufe AA.

    Stand der Konformität

    Die Website strebt die Konformität mit den Web Content Accessibility Guidelines (WCAG) 2.2, Stufe AA, an. Derzeit ist die Konformität teilweise gegeben: Die Kriterien wurden mit automatischen und manuellen Prüfungen am Code und in einem Browser überprüft, nicht mit einem externen zertifizierten Audit.

    Was geprüft wurde

    Vollständige Tastaturbedienung mit stets sichtbarem Fokus; Sprunglink zum Inhalt; nur eine Hauptüberschrift pro Seite und eine regelmäßige Überschriftenhierarchie; Farbkontraste von Text und Bedienelementen von mindestens 4,5:1; Alternativtexte für bedeutungstragende Bilder; Meldeformular mit ausdrücklichen Beschriftungen, gekennzeichneten Pflichtfeldern sowie Fehlern, die mit den Feldern verknüpft und Screenreadern angesagt werden; keine sich selbst bewegenden Inhalte; Beachtung der Einstellung zur Reduzierung von Bewegung; Mindestgröße der Bedienelemente von 24×24 Pixeln; Inhalte auch ohne JavaScript lesbar.

    Bekannte Einschränkungen

    Die Titel der Presseartikel in der Presseschau werden in der Originalsprache wiedergegeben und können unerklärte Abkürzungen enthalten. Die Bilder der Pressemitteilungen stammen aus dem früheren Archiv und haben einen auf den Titel der Mitteilung beschränkten Alternativtext. Die Spam-Prüfung des Formulars (Cloudflare Turnstile) ist eine Komponente eines Dritten: Sie läuft fast immer von selbst ab, ohne jede Interaktion; verlangt sie eine Handlung, hängt ihre Barrierefreiheit von Cloudflare ab, und wer das Formular nicht senden kann, kann direkt an die institutionelle E-Mail-Adresse schreiben. Externe Links führen zu Websites Dritter, deren Barrierefreiheit nicht von dieser Website abhängt.

    Meldungen

    Wenn Sie auf eine Barriere stoßen, schreiben Sie an die institutionelle Adresse und geben Sie die Seite und das Problem an: etelwardo.sigismondi@senato.it.

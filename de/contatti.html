    Kontakt

    Eine Meldung aus der Region oder eine Nachricht: Über das Formular gelangt sie direkt in das institutionelle Postfach des Senators.

    Formular

    Eine Meldung senden

    Ein Anliegen Ihrer Gemeinde, eine Infrastruktur, eine Dienstleistung, ein Vorschlag. Schildern Sie die Fakten mit Daten und Belegen: Die Nachricht erreicht die institutionelle E-Mail-Adresse des Senators, die Antwort kommt an die von Ihnen angegebenen Kontaktdaten.

    Mit Sternchen (*) gekennzeichnete Felder sind Pflichtfelder.

    Geben Sie Ihren Namen ein
    Geben Sie eine gültige E-Mail-Adresse ein
    Geben Sie den Betreff ein
    Schreiben Sie eine Nachricht
    Zum Senden bestätigen Sie bitte, dass Sie die Datenschutzerklärung gelesen haben

    Das Formular übermittelt die Nachricht über die Cloudflare-Infrastruktur der Website an die institutionelle E-Mail-Adresse des Senators: Auf dieser Website werden keine Daten gespeichert. Gegen Spam läuft eine automatische Prüfung (Cloudflare Turnstile), die keine Profiling-Cookies verwendet.

    Die Antwortzeiten hängen von der parlamentarischen Tätigkeit ab: Sie sind nicht garantiert.
